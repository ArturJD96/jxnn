# Json XML Node Notation

![](assets/logo.png)

This repository contains a schema for JSON containing "Json XML Node Notation" (JXNN, or "Jackson", read \[ˈd͡ʒæksn̩\]).

The main goal of this schema is to align data within the JSON syntax as close as possible to XML's, focusing on XML's ability to mix structured (elements) and unstructured (text) content.
